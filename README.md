# ITP Final project
## Type - Game Development
### Platformer Game
#### Group: SE-2512, Creators: Nurlanov Shakhriyar & Sergeev Zhansir
<br>
<br>
This project is a 2D Game based Platformer using Python Arcade library.
The project includes: multiple levels, saving system, main menu + play & game over menu, main character, enemies, traps, bullets, moving platforms, boss, ending, figthing system and so on.
<br>
## Features:

- Start Menu
- Game Over Screen
- Multiple Levels
- Enemy AI
- Moving Platforms
- Turrets and Bullets
- Spikes Traps
- Fullscreen Mode (F4)
- Score and Highscore System
- JSON Save System
- OOP Architecture
- Unit Tests
- Decorators and Generators
<br>
## Technologies:

- Python
- Arcade
- JSON
- unittest

## How to install our Project?

1. Clone repository
2. Install dependencies
Than write in terminal
pip install arcade

## How to run the project?
1. Open terminal
2. Write python main.py
